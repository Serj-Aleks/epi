# EPI

Персональная операционная система (APOTHEOS, рабочее имя EPI).

- Ядро: Haiku R1/beta6, файловая система BFS
- Интерфейс: браузер вместо рабочего стола
- Загрузка: с устройства; по сети (PXE) — дополнительно
- Свой скрипт `script` на формате ASON: модель — два равнозначных слота, предикации обрабатываются интерпретаторами через диспетчер; язык реализации — Go

Спецификация модели и скрипта — `claude/ason-spec.md` в проекте (раздел 9 — решения по шагам).

## Где мы сейчас

Этапы 1 (эталон) и 2 (ТЕМП на Haiku) пройдены: собственный образ Haiku R1/beta6 (коммит 874f0cea9d, ревизия hrev59866+79) загружается на стенде. Приоритет — скрипт и персистентность; этап 3 «Оболочка» продолжится после.

### Скрипт (`script/`)

Запуск на Lenovo — из папки `$HOME/script`: `go run ./infra`, страница `localhost:5832`.

- `format` — чтение ASON; `disp` — диспетчер предикаций и базовые интерпретаторы: `arifm`, `logic`, `trgnm`, `lnrfm`, `zycle` (`recur`), `trans` (перевод естественного текста), `nexus` (локальный контекст концепта);
- `infra` — сервер и интерфейс: темы автора (`thema/<Тема>`: протокол сеансов и концепты), системный лексикон (`lexic`), концепт — файл `.uic`, строка на модель `Параметр : значение`;
- связи концептов с обратными списками: `Taxon`, `Links`, `Prfix`, `Sufix`, `Radix`, `Attrib`, `Preposit`, синонимы `Alias`;
- граф локального контекста `nexus Имя` — как в ПИ: четыре оси (восемь сторон), подсказка следующего уровня, список всех связей;
- перенос данных ПИ выполнен 08.11.2026: темы Dictionary (24 концепта) и GLOTEON (728); код переноса (kater.go, флаг `-catlg`) удалён 10.11.2026.

В пробе (ветка `panel`, не в `main`): карточка концепта — панель рядом с лентой с линзами графа, контента и строк; редактор спутников; ссылки `[[ ]]` и трансклюзии `{{ }}`; поиск `qwest`.

### Оболочка (этап 3, на установленной Haiku — Lenovo)

- загрузка сразу в браузер: стартовая страница ждёт сеть и переходит на ui.center (`shell/start.html`);
- сторож сети: подключает Wi-Fi при загрузке и после обрывов, ведёт журнал (`net/epi-net`);
- Deskbar EPI: кнопка Θ, своя терминология меню, программы в полосе называются как в меню (`deskbar/`);
- меню EPI: свои группы и имена, латиницей (`menu/epi-menu`);
- файловый менеджер: URNA и DISKS на рабочем столе (`tracker/`);
- убраны демо и лишние программы (`system/packages` → `/boot/system/settings/packages`);
- автозапуск: сторож, панель, браузер и положение окон (`image/haiku-image.patch`);
- сборка образа EPI: `image/UserBuildConfig`, `image/fetchdeps` (Go: зависимости Firefox по собранному образу), `image/haiku-image.patch` (автозапуск EPI, без мастера первой загрузки Haiku, переключатель раскладки всегда).

Принципы меню: папка — все буквы заглавные, пункт — с заглавной; одна вещь — одно место; разные программы на одну тему — подменю одной группы. Язык интерфейса — английский, русский — для содержимого и раскладки.
