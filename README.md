# EPI

Персональная операционная система.

- Ядро: Haiku, файловая система BFS
- Интерфейс: браузер вместо рабочего стола
- Загрузка: по сети (PXE)
- Свой скрипт на формате ASON, данные — фреймы UNISON

## Где мы сейчас

Этап 1 пройден: собственный образ Haiku R1/beta6 (коммит 874f0cea9d, ревизия hrev59866+79) загружается на стенде.

Этап 3 «Оболочка» идёт на установленной Haiku (Lenovo). Сделано:

- загрузка сразу в браузер: стартовая страница ждёт сеть и переходит на ui.center (`shell/start.html`);
- сторож сети: подключает Wi-Fi при загрузке и после обрывов, ведёт журнал (`net/epi-net`);
- Deskbar EPI: кнопка Θ, своя терминология меню, программы в полосе называются как в меню (`deskbar/`);
- меню EPI: свои группы и имена, латиницей (`menu/epi-menu`);
- файловый менеджер: URNA и DISKS на рабочем столе (`tracker/`);
- убраны демо и лишние программы (`system/packages` → `/boot/system/settings/packages`);
- автозапуск: сторож, панель, браузер и положение окон (`image/haiku-image.patch`);
- сборка образа EPI: `image/UserBuildConfig`, `image/fetch-deps` (зависимости Firefox по собранному образу), `image/haiku-image.patch` (автозапуск EPI, без мастера первой загрузки Haiku, переключатель раскладки всегда).

Принципы меню: папка — все буквы заглавные, пункт — с заглавной; одна вещь — одно место; разные программы на одну тему — подменю одной группы. Язык интерфейса — английский, русский — для содержимого и раскладки.

Следующее: страница-лаунчер в браузере, мастер первого запуска, Chromium вместо Firefox.

## Что отмечать при каждой проверке

Фиксируется заранее, чтобы не выяснять задним числом. Записывать: диск или флешка, что сделано, что увидели.

- Firefox отвечает: через какое время после запуска и после каких действий перестал реагировать на кнопки и закрытие (если перестал).
- Finish выключает компьютер; если нет — какое окно осталось.
- Сеть: через сколько подключилась, открылся ли ui.center сам.
- Логотип APOTHEOS в правом верхнем углу, чёрный фон.
- Видео и звук (например, YouTube).
