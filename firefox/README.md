# Профиль Firefox в образе EPI

Firefox привязывает профиль к месту установки: `[Install<хеш>]` в `profiles.ini` и `installs.ini`. Без этой привязки он игнорирует готовый профиль и создаёт свой, чистый.

Хеш — CityHash64 (v1.0) от пути к каталогу Firefox в UTF-16LE, заглавными шестнадцатеричными цифрами. Для `/boot/system/apps/Firefox` это `C5BA4F3893AD78E4`. Он одинаков на любой машине с этим образом. Алгоритм проверен по известным значениям: `C:\Program Files\Mozilla Firefox` → `308046B0AF4A39CB`, `/usr/lib/firefox` → `4F96D1932A9F858E`.

`epi.default/user.js` — настройки EPI: без автономного режима при запуске без сети, без приветственных страниц, без восстановления сеанса.
